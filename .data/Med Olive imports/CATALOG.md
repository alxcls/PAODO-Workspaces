Premium Mediterranean olives and cold-pressed olive oil, imported in bulk.
Batch size: 5,000 g olives + 5,000 ml olive oil per import run.

## Products

| Ingredient | Unit  | Price / Unit |
|------------|-------|--------------|

## How to Order

Run `python scripts/check_catalog.py` to see live stock.

To buy: `python scripts/sell_stock.py <ingredient> <quantity> "<your name>"`

Both products arrive together per import — ask us to run an import when stock is low.
